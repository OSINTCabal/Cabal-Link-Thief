# Changelog

All notable changes to Cabal-Link-Thief will be documented here.

## 1.0.0 - 2026-09-21

### Added

- Common-subdomain DNS discovery
- HTTP/HTTPS root-page scanning
- Email, phone, social-profile, IPv4, street-address, name, and job-title extraction
- HTML link collection and URL normalization
- Per-subdomain deduplication and reporting
- JSON and Markdown export
- Animated terminal interface
- Initial GitHub repository documentation and packaging files
